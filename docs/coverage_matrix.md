# Матрица покрытия UI-автотестами

Снято с dev-стенда обходом портала (04.08.2026). Только UI — API-матрица
в [api_coverage_matrix.md](api_coverage_matrix.md).

Одна строка = один тест. Статусы: ✅ написан · 🔶 написан, в skip · ❌ нужно написать

Набор: **smoke** — короткий прогон на каждый деплой (быстрые критичные
сценарии, входят и в регресс); **regress** — полный набор.

Среда: **все** — безопасен и для прода (read-only или действия в рамках
своей тестовой учётки, невидимые третьим лицам); **dev/qa** — создаёт данные,
мутирует публичное состояние или затрагивает третьих лиц (заявки, отклики,
лайки с публичным счётчиком) — на проде не запускать.
